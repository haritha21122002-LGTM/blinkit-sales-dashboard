# 📊 Blinkit Sales Dashboard

A data visualization and business intelligence project built using **Power BI and DAX** to analyze Blinkit sales data and generate meaningful insights through an interactive dashboard.

## 📌 Project Overview

This project focuses on analyzing Blinkit sales data to understand:

- Sales performance across product categories
- Monthly sales trends
- Revenue generated by cities
- Product quantity and product count
- Estimated profit performance
- Organic vs non-organic products
- Seller-wise performance
- Customer review trends

## 🧮 DAX Analysis

DAX measures were created to calculate important business metrics such as:

- Total Original Sales
- Total Products
- Total Quantity Sold
- Total Reviews
- Estimated Profit

These measures were used to create interactive KPIs and dashboard visualizations.

## 🔍 Key Insights

- Household products contribute significantly to overall revenue.
- Personal Care is another major revenue-generating category.
- Bakery and Grocery also show strong sales performance.
- Monthly sales remain relatively consistent throughout the year.
- Non-organic products represent a larger share of the total products.
- City-wise analysis helps identify geographical revenue performance.
- Seller filters allow detailed seller-level analysis.

## ▶️ How to Use

1. Open the Power BI `.pbix` file.
2. Refresh the dataset if required.
3. Explore the dashboard visualizations.
4. Use the seller filters to analyze different sellers.
5. Interact with the charts to explore sales insights.
